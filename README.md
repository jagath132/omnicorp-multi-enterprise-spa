# OmniCorp Group - Multi-Enterprise Business Single Page Application (SPA)

A modern, high-performance executive dashboard and multi-business portal built with **React**, **Vite**, and **Tailwind CSS**. Designed for multi-enterprise business owners who operate three distinct enterprises from a unified single page platform.

---

## 🌟 The 3 Enterprise Portals

### 1. 🏥 AuraCare Multi-Specialty Hospital & Healthcare Network
- **24/7 Emergency Triage Bar**: Live cardiac helpline and ER bed telemetry.
- **Centres of Clinical Excellence**: Super-specialty medical institutes (Cardiology, Neurosurgery, Orthopedics, Pediatrics, Oncology, Critical Care).
- **Chief Medical Specialists Directory**: Specialist consultation booking modal with date/time slot picker and SMS token confirmation.

### 2. 🛍️ NexTrend Direct & Retail Commerce (Amazon-Inspired Storefront)
- **Amazon Header Navigation Bar**:
  - NexTrend smile logo with curved gold indicator.
  - Location delivery selector (`Deliver to Alexander • New York 10001`).
  - Search bar with department dropdown and search button (`#febd69`).
  - `Hello, [User] - Account & Lists` hover dropdown with quick Sign In / Sign Out, Wish Lists, and Orders.
  - Returns & Orders and Cart widget with live item counter.
- **Sub-Nav Bar**: `☰ All` side drawer and category filters (*Today's Deals*, *Electronics*, *Fashion*, *Smart Wearables*, *Home & Living*).
- **Promotional Carousel Banners & 4-Grid Quad Category Cards**.
- **Today's Deals Lightning Strip**: Live countdown timer and discount tags.
- **Amazon Product Cards**: Star ratings, review counts, and **`✓prime Free Delivery Tomorrow`** badge.
- **Amazon Sign-In Portal (`AmazonSignIn.jsx`)**: Complete authentication flow with demo quick-login.
- **Shopping Cart Drawer & Checkout Flow**.

### 3. ⚡ VoltDrive Mobility & Fleet Logistics (EV Automotive & Luxury Fleet)
- **Live Zero-Emission Fleet Telematics**: Connected vehicles and 120 supercharging hub network tracker.
- **Virtual Vehicle Showroom**: High-performance EV catalog (VoltDrive GT Apex Hyper-Sedan, AeroPulse X-700 SUV, Lumina Grand VIP Limousine, CyberCargo Commercial Van).
- **Interactive Book a Test Drive / Chauffeur Modal**: VIP showroom trials, executive chauffeur transfers, and doorstep delivery bookings.
- **Interactive Corporate Fleet Lease Estimator**: Custom volume slider (1 to 100+ EVs), lease term selector, and live **Annual Gas Fuel Savings** calculator.
- **Turnkey Corporate Fleet Packages**.

---

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + Custom Glassmorphism UI
- **Icons**: Lucide React
- **State Management**: React Context API (`AuthContext`)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/jagath132/omnicorp-multi-enterprise-spa.git
cd omnicorp-multi-enterprise-spa
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
